# Pause Fable for the presentation

Fable 5.1 has unfinished Claude Code trials. Shiv paused them for the October 28 presentation and plans to resume later.
The voting-page task update must not restart Fable when it reaches main.

## The decision

Remove Fable's model, Claude Code agent, and vanilla agent from the default job settings while the pause lasts.
The existing planner then excludes Fable from automatic and default manual runs.
The catalog omits Fable, so the board hides it in both Internet and Model only views.

Keep every saved row and artifact. Keep task hashes, scoring, retry rules, and the two-trial setting unchanged.
Automatic main-branch runs continue for the other eight models.

## Resuming

When Shiv resumes Fable, restore the three job entries before planning its remaining trials.
The board will show its saved results again. The planner will reuse scored identities and apply the existing retry rules.
Use an explicit budget for any remaining paid work.

Merge this pause before the voting-page update. A fresh voting-page task then selects 16 Internet trials across eight agents.
